# 📊 Data Engineering and Analytics Projects

> A collection of practical Python projects focused on **data collection, API integration, web scraping, data cleaning, data processing, and exploratory data analysis.**

---

## 🚀 Projects

### 1. 🪙 Cryptocurrency Market Data

A data collection and analysis project using the **CoinGecko API** to retrieve cryptocurrency market information.

#### 🔑 Key Activities

- 🔗 API integration
- 🪙 Cryptocurrency data collection
- 🐼 Data processing using Pandas
- 🧹 Data cleaning
- 📊 Exploratory data analysis
- 📁 Cleaned dataset generation

#### 🛠️ Technologies

- Python
- Pandas
- Requests
- CoinGecko API
- Python-dotenv
- Jupyter Notebook

---

### 2. 📚 Book Information Web Scraping

A web scraping project that collects book information from **Books to Scrape** using Python.

#### 🔑 Key Activities

- 🌐 HTTP requests
- 🔎 HTML parsing
- 🕷️ Web scraping using BeautifulSoup
- 📥 Data extraction
- 🐼 DataFrame creation
- 🧹 Data cleaning and processing
- 📁 CSV dataset generation

#### 🛠️ Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook
